RAM parking defaults to off (`--conversation-cache-mib 0`); default slots are four. `--prompt-cache 0` disables it and also makes disk sessions invalid. RAM parking matches exact token/image prefixes and steering mode, rather than a supplied conversation ID. Restoring replaces active authoritative KV and recurrent/PLE/indexer state and updates `live`, `live_imgs`, `checks`, `check_clock` and `cvec_cached`. Streamed VRAM maps reset so the next resolve refills them; the draft ring refills from its authoritative copy. All incoming layers/checkpoints validate before device writes. Allocation/admission failures skip RAM parking and re-read the prompt; transfer failures are fatal rather than continued partial state.
